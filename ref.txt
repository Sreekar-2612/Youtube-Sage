5.React gives the previous messages to the function as:prev
...prev copies all the exisiting messages into a new array

the pattern is setMessages((prev) => [...prev,newMessage]);--> means keep all the old messages and add one new message at the end.

6.why use prev?
Why?
React state updates may not happen immediately.
Since this function updates messages multiple times,
prev guarantees that you receive the latest available
message list.
